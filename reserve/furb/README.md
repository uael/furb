# furb

This crate holds the name `furb` on crates.io for [the crate of furb](https://github.com/uael/furb). It has no code,
so do not depend on it.

The crate of furb comes here when its dependencies stand on crates.io. Take it from its repository:

```sh
cargo add furb --git https://github.com/uael/furb
```

Copy the `Cargo.lock` of furb into the new crate before its first build, since a newer version of a dependency can
break the build.
