# furb

This crate holds the name `furb` on crates.io for the crate of furb, a work in progress at
https://github.com/uael/furb. It has no code, so do not depend on it.

The crate of furb comes here as its first release when its dependencies stand on crates.io. Until then, take it from
its repository:

```sh
cargo add furb --git https://github.com/uael/furb
```
